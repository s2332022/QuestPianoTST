「十分な効果」の実用閾値をデータ閲覧前に定める：X ___ mm、Y ___ mm、Z ___ mm、悪化率上限 ___、副作用上限 ___。未定義の改善率は空欄にし、Rawゼロの割合も報告する。少人数では探索的とし、有意差を無理に主張しない。成功サンプルだけを取り出した効果を全条件の効果と取り違えない。

- A：正しい指を指定したとき効果が十分で、手動割当が演奏範囲を制限する → 自動押鍵指推定を検討。該当する課題・制約・必要性能を列挙する。
- B：正しい指でも効果が弱い、または副作用が大きい → 補正アルゴリズムと条件設計を先に改善する。
- C：手動指定で研究目的を達成できる → 自動推定は将来課題とする。
- データ不足・条件混在 → 追加測定し、A/B/Cを確定しない。
